centre size effort poses

centre = where the box sits (Å). size = how big the box is (Å); bigger means a wider search and a longer run. effort = Vina exhaustiveness: how many independent searches run, 8 for a quick look, 32–64 for a result worth keeping. poses = the most poses to return (Vina --num-modes, 9); fewer come back when the searches only find a few genuinely different pockets, so effort — not poses — controls how complete the answer is.
